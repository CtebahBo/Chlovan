CHLOVAN V6 — INSTALLATION

1. VERSION
La V6 est autonome : le MENU, REPAS, COURSE, QUE PUIS-JE FAIRE ? et TO DO fonctionnent sans Google Sheets pour l'utilisation quotidienne.
Les tâches sont stockées localement dans le navigateur via localStorage.

2. IMPORTANT — DONNÉES V5
Au premier lancement, si le cache local CHLOVAN V5 existe dans le même navigateur, la V6 récupère automatiquement les tâches présentes dans ce cache.
Si les tâches n'existent que dans Google Sheets et n'ont jamais été chargées dans le cache V5, elles ne peuvent pas être récupérées automatiquement par cette version autonome. Dans ce cas, conserver la V5 le temps de faire une migration manuelle/export avant de supprimer l'ancien système.

3. UTILISATION SUR PC
Ouvrir Index_V6.html dans un navigateur pour tester l'interface.
Pour une vraie installation PWA/offline, publier tout le dossier sur un hébergement HTTPS statique (par exemple GitHub Pages, Cloudflare Pages ou Netlify). Le fichier manifest.json et sw.js doivent rester à côté de Index_V6.html.

4. IPHONE
Une fois l'app publiée en HTTPS :
Safari → bouton Partager → Ajouter à l’écran d’accueil.
L'app s'ouvre ensuite en mode application grâce au manifest/PWA.

5. ANDROID
Chrome → menu ⋮ → Ajouter à l'écran d'accueil / Installer l'application.

6. SAUVEGARDE TO DO
Dans TO DO, les boutons Sauvegarder et Restaurer permettent respectivement d'exporter/importer un fichier JSON.
C'est important car les données locales ne sont pas automatiquement synchronisées entre plusieurs appareils/navigateurs.

7. ARCHIVAGE MENU
Le passage à une nouvelle semaine est détecté automatiquement à l'ouverture de l'application. Si l'app est fermée exactement à lundi 00:00, elle ne peut évidemment pas exécuter du code à cet instant ; dès la prochaine ouverture lundi, l'ancienne semaine est archivée et la nouvelle semaine devient active.
